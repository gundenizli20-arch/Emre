# Shortcut Studio

Site vitrine pour une entreprise de clipping vidéo (TikTok, Reels, YouTube Shorts).

Tout le site est dans `index.html`.

## Ce qu'il faut personnaliser
- Le nom "Shortcut Studio" : utilisez la recherche/remplacement.
- `EMAIL_RECEPTION` (en bas du fichier) : votre adresse pour recevoir les devis.
- L'e-mail et l'Instagram dans la section Contact.
- Les prix dans la section Tarifs.
- Les vidéos de démo : identifiant YouTube Shorts dans `data-youtube=""`.
